# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion about the work. Harassment, personal attacks and discriminatory language aren't welcome in issues, pull requests or anywhere else the project lives.

Report unacceptable behaviour privately to the maintainer, [@mybuddyandrew](https://github.com/mybuddyandrew), through the contact details on their GitHub profile. Reports are kept confidential.
